# 📚 Let's Learn

> **Let's Learn** is an educational website created for **SSC CGL aspirants**, providing a centralized platform for exam-oriented study material, previous year papers, mock tests, YouTube learning resources, current affairs, daily learning content, and daily quizzes.
>
> The goal of Let's Learn is to make SSC CGL preparation **simple, organized, consistent, and accessible** by bringing useful resources together in one place.

---

## 🌐 Live Demo

### 👉 [Visit Let's Learn](https://sourabh-prajapat.github.io/Lets-Learn/)

**Let's Learn** is an educational website created for **SSC CGL aspirants**, providing a centralized platform for exam-oriented study material, previous year papers, mock tests, YouTube learning resources, current affairs, daily learning content, and daily quizzes.

The website is designed to make SSC CGL preparation **simple, organized, consistent, and accessible** by bringing useful resources together in one place.

---

## 🎯 Purpose

Preparing for SSC CGL often requires using multiple sources for different subjects and topics. Let's Learn brings these resources together and provides regularly updated content to help aspirants study efficiently.

The platform focuses on:

* 📄 SSC CGL Previous Year Papers
* 📝 Mock Tests
* ▶️ Recommended YouTube Classes
* 📰 Daily Current Affairs
* 📖 Daily Vocabulary & English Learning
* 🧠 Daily Quizzes
* 📅 Weekly Current Affairs Quiz
* 📚 Exam-oriented General Knowledge & General Studies

# 📖 Daily Learning

The Daily Learning section provides focused learning content every day.

It is divided into three parts.

### 1. 📚 Daily Vocabulary

Every day, **5 vocabulary words** are provided with:

* English meaning
* Hindi meaning
* Example
* Synonym
* Antonym
* Explanation

### 2. 🔤 One Word Substitution

Every day, **5 OWS** are provided with:

* Phrase
* Hindi meaning
* Explanation

### 3. 💬 Idioms

Every day, **5 idioms** are provided with:

* Hindi meaning
* Example
* Explanation

---

# 🧠 Quizzes

Let's Learn provides two daily quizzes.

## 🇬🇧 English Quiz

The English Quiz contains **10 questions** based on previously covered Daily Learning content.

Topics include:

* Vocabulary
* One Word Substitution
* Idioms

## 🌍 GK/GS Quiz

The GK/GS Quiz contains **10 questions** covering:

* History
* Geography
* Polity
* Science
* Current Affairs

Both quizzes are updated daily.

---

# 📅 Sunday Special Current Affairs Quiz

Every **Sunday**, Let's Learn provides a special Current Affairs Quiz.

The quiz contains questions based on the **current affairs of the previous 7 days**.

This provides students with a weekly revision and practice session.

---

# 🔗 Google Sheets API Integration

Let's Learn is connected to a **Google Sheets API / Apps Script** system for managing regularly updated content.

It is used for:

* 📰 Current Affairs
* 📖 Daily Learning
* 🧠 Daily Quizzes

The Google Sheets-based system makes it easier to update daily content without making major changes to the website's frontend.

### Data Flow

```text
Google Sheets
      │
      ▼
Google Apps Script / API
      │
      ▼
JavaScript
      │
      ▼
Let's Learn
      │
      ▼
Students
```
